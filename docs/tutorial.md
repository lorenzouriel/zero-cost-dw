# Tutorial

A complete build-along guide, covering every step taken to create this project, is available as a PDF:

**[tutorial-pt-br.pdf](tutorial/tutorial-pt-br.pdf)** — written in **Brazilian Portuguese**.

The English documentation in this folder covers the same ground as reference material ([architecture](architecture.md), [data model](data-model.md), [ETL](etl.md), [OLAP](olap.md), [dashboard](dashboard.md), [getting started](getting-started.md)). The PDF adds the walkthrough narrative — interviews, design reasoning and screenshots of each Visual Studio and Power BI step. Use the [glossary](glossary.md) to match its Portuguese terms to the English ones.

## Contents of the PDF

1. **First contact** — scenario and challenges; tools
2. **Initial sources** — source information
3. **Facts vs. dimensions** — interviews; dimensions and matrix; creating the facts; calculated indicators
4. **ETL, OLAP and SQL** — creating the services in Visual Studio (Database, SSIS, SSAS); creating the tables; deploying to SQL Server; ETL; OLAP
5. **BI** — dashboard; creating a free Power BI Service account; workspace and dashboard deployment; configuring the OLAP gateway (what the gateway is, configuring it, how the connection to Analysis Services works)
6. **Architecture**
7. **Organisation**
